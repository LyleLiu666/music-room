## 基线

现有项目此前没有 Git 仓库，已建立代码、音色、原始作品和设计文档基线。原有 10 项单元测试通过。

## 第一轮：目录与工作台

- 歌曲和版本以独立 ID 关联，目录校验分组、默认版本、独立文件路径与段落对应索引。
- 左侧作品库、整曲概览、4/8 小节局部查看和可展开混音器已实现；曲尾窗口显示实际剩余小节。
- 版本直达、无效地址提示、前进后退、普通切换停止旧声音有效；总音量保留，其他混音重置。
- 14 项单元测试通过；浏览器验证分组、局部窗口、段落跳转、实际播放、混音恢复、导航、MIDI 和 390 px 窄屏操作，无页面错误；构建通过。
- 代码复查修复：空格快捷键避开面板展开控件与其他交互控件，选中版本自动展开所属歌曲。试听和可视范围均不改写乐谱。
- 浏览器脚本：`npm run verify:workbench`；报告和截图位于忽略提交的 `test-results/workbench/`，不会覆盖原作品。
