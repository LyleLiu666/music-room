# Music Room · 代码音乐作品库

纯前端作品库，支持多首曲目和同一首曲子的多个版本。每个条目独立保存乐谱、MIDI 和成品音频，共用播放器、音色与混音界面。演奏、混音和 WAV 渲染都在浏览器本机完成，不使用业务后台、在线模型或付费 API。

下一版规划见 [音乐工作台设计](docs/design/music-workbench.md)：借鉴 MuseScore 的工作方式，设计歌曲与版本分组、片段放大、循环试听和 A/B 比较。该文档为待实施方案，下文描述当前已实现能力。

## 开始试听

使用 Node.js 22.18+，推荐 Node.js 24 或更新版本。

```sh
npm ci
npm run dev -- --port 5173
```

打开 `http://127.0.0.1:5173`，在页面顶部选择作品。第一次播放读取项目内约 21 MB 音色文件，曲目切换复用已加载的音色，不访问第三方音色服务。

- 播放 / 暂停，或在非表单区域按空格。
- 点击段落、音符时间线或拖动进度条跳转。
- M 静音，S 独奏；可以同时独奏多条轨道，静音优先。
- 调整轨道音量、总音量或切换旋律音色。
- 切换作品会停止上一首，并重置播放位置和临时混音。
- 导出 WAV 使用点击时的曲目、音色和混音快照；随后切换作品不会改变正在导出的内容。
- MIDI、乐谱和成品下载跟随当前作品。MIDI 的声音取决于接收软件的音源。

页面地址中的 `#rain-letter-v1` 或 `#rain-letter-v2` 可以直接选择对应版本。

## 技术与音色

| 层次 | 选择 |
| --- | --- |
| 乐谱、作品目录、界面 | TypeScript（Apache-2.0） |
| 演奏、效果、离线渲染 | 浏览器原生 Web Audio |
| 开发与静态打包 | Vite（MIT） |
| MIDI 交换 | @tonejs/midi（MIT） |
| 钢琴采样 | Alexander Holm 的 Salamander Grand Piano（CC BY 3.0） |
| 弦乐、长笛采样 | VSCO 2 Community Edition（CC0） |
| 电钢琴、拨弦、贝斯、鼓 | 项目代码合成（MIT） |
| 浏览器验证 | Playwright（Apache-2.0） |

不要求 Python、FluidSynth 或桌面工作站。乐谱 JSON、作曲源码及本地音色共同构成可重建的作品工程；MIDI 单独不保存本项目的音色、效果和混音。

没有订阅或按生成次数收费。钢琴采样需随作品分发保留署名。许可说明见 [署名页](public/credits.html)，来源、固定提交与 SHA-256 见 [资产清单](public/samples/manifest.json)。钢琴使用单一力度层，弦乐与长笛使用部分持续音采样；拨弦是物理建模合成音色，不是真实古筝采样。

## 曲目组织与新增作品

| 文件 | 职责 |
| --- | --- |
| `src/catalog.ts` | 作品入口：身份、标题、版本、介绍、作曲函数与文件位置 |
| `src/songs/rain-letter-v1.ts` | 第一版独立乐谱与编曲 |
| `src/songs/rain-letter-v2.ts` | 第二版 riff、回答句与编曲 |
| `src/music/score.ts` | 共用乐谱类型和乐器轨道定义 |
| `src/audio.ts` | 音色加载、合成、播放、混音和离线渲染 |
| `src/midi.ts`、`src/wav.ts` | MIDI 与双声道 PCM WAV 编码 |
| `src/main.ts` | 作品选择、混音交互、音符时间线与实时频谱 |

增加新曲目时，在 `src/songs/` 编写独立作曲函数，并在 `src/catalog.ts` 的 `SONGS` 中添加条目。不同曲子可以有不同标题、速度、时长和段落；同一曲子的版本使用独立 ID。导出路径必须独立，避免覆盖旧作品。

MIDI 使用 `englishTitle` 或曲目 ID 保存 ASCII 标题；新段落可用 `midiName` 指定导出标记。中文信息完整保留在页面和 JSON 中。

`npm run export:score` 为注册作品分别生成 MIDI 和 JSON。WAV 在浏览器选择对应作品后导出，默认混音成品保存到该条目的 `files.wav` 位置。新增作品不需要复制页面。

## 验证与静态发布

```sh
npm test
npm run export:score
npm run build
npm run preview -- --port 5174
```

将 `dist/` 放到静态托管环境即可。Vite 服务仅用于开发或预览。模块和采样读取需要 HTTP 服务，不能直接双击 HTML。

端到端验证默认使用 macOS 已安装的 Google Chrome：

```sh
MUSIC_ROOM_URL=http://127.0.0.1:5174 npm run verify:browser
```

脚本验证播放、暂停、跳转、混音路由、切换停止旧曲、切换重置混音、独立 MIDI 导出，以及导出途中切换作品的快照一致性。实际生成第二版三分钟 WAV，检查时长、声道、削波、异常静音和尾音衰减；另有另一速度、四秒时长的静音乐谱导出验证。

结果与桌面、手机截图保存在 `public/exports/rain-letter-v2/`。自动检查保证文件和交互可靠，音乐审美由试听判断。重新生成成品后，再构建静态产物。

`npm run assets` 可以补回缺失音色，复用哈希正确的现有文件，不依赖临时目录。
