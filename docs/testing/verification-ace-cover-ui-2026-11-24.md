# 「翻唱这段」浏览器验收（2026-11-24）

第 2 轮接入当前版本操作行、非模态选段面板、完整波形、循环试听及同位置对听。翻唱结果还原原曲选段的相对时间，重新演绎的歌词可能在不同拍子出现。面板提供四组唱法与乐队设置和自定义描述。本机真实模型试听覆盖摇滚配置，其他预设的音色和唱词仍需分别听评。

## 验收记录

- 首次 Chrome 测试发现底部播放条盖住提交按钮。同期画面显示浏览器安全策略阻止波形解码读取临时 URL。保留失败日志。修正底栏宽度，波形使用已有音频缓存。
- 固定数据和推理替身验证所选时间数字、鼠标拖动、键盘边界与波形一致。循环试听时主区和列表播放状态同步。验证翻唱第 12 秒切换到原唱第 27 秒，原唱完整时长、描述与成品选择保留。改变成品选择时列表与操作行同步。
- 同步歌词按区间重叠辅助填写。普通歌词的顺序估算和校对提示见[最终集成验收](verification-cover-live-release-2026-11-24.md)。
- 日间、夜间及 390 px 小窗用同一浏览器用例验收。首轮和复验日志位于本机 `test-results/ace-cover-2026-11-24/`，浏览器截图位于 `test-results/ace-cover-ui/`。
- 本轮由两种浏览器验证实际界面，模型替身独立于[真实模型验证](verification-ace-cover-backend-2026-11-24.md)。
