# 声音创作空间

## 产品范围

当前集中做好音乐、语音和音色转换，把本机计算资源用于声音生成与处理。**不做封面能力，不接入文生图**：不增加封面创作入口、封面版本管理、图片生成任务或图片模型安装项。

视觉探索旧稿中的「短片封面」已取消，不能作为开发依据。已有图片、视频或文档的导入属于另行讨论的素材管理需求，不在本次范围内。

## 主流程

首页按 **项目 → 声音 → 版本** 组织。项目可同时包含音乐片段、完整音乐和语音。用户选择声音类型，不按模型选择入口。

1. 创建项目，只填写名称。
2. 新建声音，选择类型和名称。
3. 填写创作要求；音乐使用 YuE2，普通语音使用 IndexTTS 2.0。
4. 试听结果，再创作、保留灵感、选为成品或删除。

默认工作区只展示当前声音的播放器和版本列表。「再创作一版」打开创作表单；「修改这版」带入原始要求并记录来源。表单草稿随声音保存，不随试听版本切换丢失。

音乐生成时，当前版本和后台任务面板同时展示两条进度：上方五格对应规划旋律与和弦 → 生成音乐内容 → 准备声音合成 → 合成声音 → 导出与保存，使用颜色区分已完成、当前和待进行阶段；下方显示当前阶段的百分比与真实小步数量（例如 4 / 32），未知总量时显示「进度待定」。不把阶段数量当作总耗时百分比。排队和初始模型加载时不标记阶段已完成。总运行时间从任务实际开始计算，不包含排队；当前环节耗时采用引擎报告，耗时、阶段预计剩余时间和服务状态合并显示。长时间没有新进度时撤下估计并单独提示状态。

## 声音库

侧栏「音色库」下方提供「声音库」。音色库保存生成时的参考音色，声音库收录可直接试听、下载的完整音频。

- 宽窗口顶部为两排：标题、数量、页签和导入同排；搜索、分类、排序和播放同排。列表采用紧凑行，来源与版本随声音展示；批量添加只在勾选后出现，不常驻操作说明。窄工作区自动换行，下载与来源入口在选中声音后显示。
- 所有项目中选为成品或保留为灵感的已完成音频自动收录。同一版兼有两个标记，只显示一条并保留两个标记；普通尝试、失败版本和尚未合成的乐谱不收录。
- 保留来源项目和版本，可返回来源继续编辑。列表不受当前项目或转换版本分页影响；来源改名、取消收录标记、删除与恢复时同步变化。
- 支持按成品、灵感、外部导入分类，按名称和项目搜索，按创建时间或名称排序。服务端分页，每页 20 / 50 条；搜索和分类覆盖全部页。后台更新保留查找条件和当前页，不打断播放。声音库浏览时，工作台同步只返回变化标记及必要版本，不重复传输整库声音和创作详情。
- 点击某条声音从该条开始顺序播放；“播放全部”覆盖当前查找条件的全部页。开始时确定播放队列，后续翻页、搜索和收录变化不会重排队列。队列只保存声音 ID，按需读取当前音频；队列面板也按 20 条分页。
- “播放全部”旁的菜单可选顺序播放或随机播放，作用于当前筛选结果或播放列表的全部页。随机播放先生成完整的临时队列，一轮内每首仅出现一次，播完停止；上一首、下一首沿此队列移动。切换到随机方式保留当前声音，切回其他方式恢复原队列顺序；不改写保存的播放列表。
- 底部播放器提供上一首、下一首、顺序 / 列表循环 / 单曲循环 / 随机及队列入口。声音库的播放器长期保留在页面工作区之外，切换项目、音色库或任务列表不打断播放；其他播放器显式开始播放时暂停声音库播放。刷新时恢复本浏览器记录的队列（含随机顺序）、方式与进度，等待点击继续，不自动出声。
- “播放列表”页签支持创建、重命名、批量添加、上移 / 下移和移除。列表及顺序保存在工作目录 `sound-library/playlists.json`，只引用所选具体版本，不复制音频；新生成版本或成品选择变化不会替换已保存版本。取消收录标记不会使已保存版本失效，来源删除后保留不可用条目的名称和位置。删除列表不删除音频。
- 列表保存带修订号，拒绝覆盖其他窗口的新修改；相同成功保存的重复请求可恢复结果。播放列表及播放队列最多 20,000 首。快速切歌时取消旧音频读取并拒绝过期结果；明确缺失的音频可跳过，连续多首不可用时暂停，服务故障时保留队列等待重试。
- 外部导入使用文件选择器，支持 WAV / FLAC，最多 100 MiB、10 分钟，1–2 声道、8–96 kHz。校验文件后保存完整原文件副本，不依赖原目录，不生成音色或启动模型。原文件导入与播放读取共用单个缓冲区名额，不占模型执行队列，生成过程中也可导入。
- 外部音频及清单独立保存在工作目录的 `sound-library/`；项目音频保留原归属，不另建隐藏项目或重复复制。上传重试使用同一请求 ID，已提交的同一请求不会重复收录。

## AI 编曲与音乐生成

音乐创作支持 YuE2 自主作曲，也支持 Agent 写谱或按听评尝试改谱后生成音频；按用户需求选择，不默认让 Agent 重写整曲。直接按目标长度创作，不强制经过短样试听。MIDI / JSON 保留用于音符编辑、音轨调整与导出，放在辅助工具中。

创作表单提供“复制给 AI 的编曲要求”，携带当前风格、作品形式、歌词、时长、乐谱、生成设置及来源版本。工作区的“AI 编曲与导入”则带入当前试听版本。复制不启动任务；用户须交给已连接 Music Room 的外部 Agent 执行，产品当前没有内置对话作曲服务。

MCP 连接说明与生成工具指向 `get_music_creation_guide`，资源 `music-room://music/creation-guide` 返回同一份指南；网页编曲要求复用同源原则。指南明确乐器的主次搭配、进入退出与轮换，以及 riff 每次回归的变奏和留白。采用写谱或改谱方式时提供完整 YuE2 ABC；自主作曲且未指定乐谱时可省略 abc。检查时长和模型输入后提交 `studio_generate`，保留来源与旧版；不走旧的 MIDI / JSON 合成成品路线。变奏、对比与回归由乐谱表达，禁止用机械复制或音频循环凑满目标时长。直接由 YuE2 自行创作的原入口仍可使用。

当前用户认为《热带回旋》Agent 版变化增多，但整体听感不如音乐模型自主创作。这是单曲反馈，不能证明 Agent 能稳定规避重复或改进听感；改谱与乐器轮换等技巧只是可尝试的方法，最终需试听比较。

## 同步歌词规划

正式播放器已支持已保存时间轴的歌词高亮、滚动跟随、收起展开和 LRC 下载；只有输入歌词的版本可显示参考词，明确标注尚未同步。通过播放器“生成同步歌词”按钮显式启动本地 ASR，导入与操作见[歌词使用说明](../lyrics.md)，生成设计见[同步歌词设计](synchronized-lyrics.md)。

## 语音情绪

情绪描述指定「是什么情绪」，情绪强度指定「表现得多明显」。表单提供「情绪非常平淡 / 情绪平淡 / 情绪一般 / 情绪强烈 / 情绪非常强烈」，新创作默认一般，实际采用首轮试听的平淡强度；描述留空时强度也用于调节参考人声的情绪影响。强度不承诺某一种音调或中性效果。

草稿和版本独立保存设置，「修改这版」带回原值。历史记录缺少强度时保留原参数规则，不因新默认改变重放行为；表单显示原规则对应档位，用户主动换档后才写入新设置。新低档数值仍为试听候选，已有档位 ID 和实际参数保持不变，见[推理引擎说明](../tts-native-engine.md)。

## 次要操作

- 项目、片段和音色名称旁的「⋯」：重命名、删除。项目和片段删除前展示包含的片段与版本数量。
- 版本菜单：查看创作要求、删除；版本列表展示生成时的音色和情绪，音色改名或删除后保留历史名称。极旧记录缺少名称快照时，首次读取保存现存名称，音色已不存在则显示「历史音色」，不推测原名。乐谱版本另有 MIDI 下载与「MIDI 与音轨」工具，在当前创作空间内打开，不进入另一套作品库。
- AI 编曲与导入：优先复制音乐编曲要求；MIDI / JSON 导入位于折叠工具区。语音继续使用 Agent 创作入口。
- 设置：模型安装、启动、日志、目录和 MCP 连接信息。
- 项目成品：下载各声音已选的版本。
- 侧栏回收站：统一查看项目、片段、版本和音色，支持恢复与需再次确认的彻底删除。父级在回收站时，子项随父级显示，恢复父级后再分别管理。

三个生成引擎的统一调度、硬件预算与设置页演进见[模型服务与硬件资源管理](model-resource-management.md)。

没有音频的乐谱必须先生成试听文件。只有音频的版本不显示虚假的 MIDI、分轨或转录能力。音乐选择目标时长后，乐谱与最终音频均须通过 ±15% 范围检查；乐谱最多规划三次，不达标报错，最终音频不达标也不显示成功。自带乐谱时长不符须先修改，系统不自动改谱。选择“由模型决定”则保留自由时长。

## MIDI 与音轨的归属

所有创作操作都围绕 **项目 → 声音片段 → 版本**。MIDI、乐谱和音频是版本的素材与加工结果，不建立第二套导航。

| 原独立页面能力 | 当前入口与规则 |
| --- | --- |
| 作品库、版本切换、普通试听比较 | 项目中的声音片段与版本列表 |
| MIDI / JSON 导入、Agent 创作包 | 当前片段的「AI 编曲与导入」折叠工具区；新结果进入这个片段 |
| MIDI 合成音频 | 乐谱版本的「生成试听音频」，后台任务状态显示在当前版本 |
| 整曲概览、音符、小节选择、循环 | 版本菜单的「MIDI 与音轨」，工具标题始终显示项目、片段和版本 |
| 静音、独奏、音量、旋律音色 | 同一工具的混音器；「保存为新版本」保存来源与混音参数，再后台合成。原版和已选成品不变 |
| 按段落对齐的 A/B | 工具内只比较当前片段的乐谱版本；要求明确对应段落、相同速度与等长段落，不能比较其他片段 |
| WAV / MIDI / JSON 导出 | 当前版本内下载；工具的「导出试听 WAV」是点击时完整乐谱与混音的下载快照，不受选区限制 |
| 整版与局部听评 | 工具内保存到正在试听的乐谱版本，所选小节转换为秒数范围，Agent 可读取 |
| 安装、模型日志、MCP 配置 | 统一设置 |

MIDI 工具按需加载；关闭、按 Escape 或离开页面时停止其音频并释放音频上下文。保存混音任务由后台继续执行，切换页面不会改变结果归属。再次打开混音版时恢复该版本保存的混音。重试同一保存请求不能重复创建版本。

音频转 MIDI 尚未接入，不显示可用转换按钮。未来转换应从当前版本发起，结果保留在同一片段并记录来源；提取为独立创作目标时才另建片段。这是后续范围，不是本轮已实现能力。

## 删除与恢复规则

项目和片段使用独立删除标记，其下内容随所属层级隐藏。恢复时保留原来的片段、版本状态及成品选择；之前单独删除的版本继续留在回收站。单个版本删除会清除该版本的成品选择，单独恢复版本不重新选成品。

音色移入回收站后退出可选列表；生成时的音色名称保存在版本中，已有音频继续可用。参考人声正在清理或被排队/运行任务使用时，拒绝删除音色。项目、片段和版本包含未完成的生成或乐谱渲染时，需要先取消或等待完成。

彻底删除只允许处理回收站中的内容，移除该范围内保存的音频、乐谱、原音及处理后人声。全局音色独立于项目；彻底删除项目保留共享音色。保留必要的来源 ID 标记，防止旧乐谱、引擎任务及内置音色在重启或自动导入时重新出现。中途失败时保存已完成删除的记录，可继续重试；已完成的永久删除不能通过恢复撤销。

## 持久化与兼容

`studio.json` 保存声音归属、音乐版本输入、来源、灵感、成品和回收站状态。语音原始记录由 `speech/library.json` 保存；工作区同步它的真实状态。音频和乐谱仍使用原引擎的持久文件。

旧乐谱项目首次读取时作为一个声音纳入原项目。旧语音保持项目、声音和版本 ID；旧 YuE2 任务没有项目归属，单独收纳到「以前生成的音乐」。迁移不覆盖、移动或删除原文件。

新生成任务在提交时绑定声音；后续切换项目或声音不会改变结果归属。新版本不替换已选成品。删除有后代的版本不删除后代。

入口：`/` 为正式创作空间；`/speech.html` 为同页兼容入口。旧 `/score.html#版本ID` 地址自动回到对应项目、声音片段和版本；版本不存在或已删除时明确提示，不打开其他乐谱冒充。独立作品库页面已退役。

## 验证

- `npm run test:service`：后端所有权、迁移、跨项目乐谱导入、层级删除恢复、忙碌保护、永久删除重试、种子内容与内置音色防重建、重启及原有生成/文件边界。
- `npm run verify:studio`：使用隔离工作目录和测试引擎走正式首页，覆盖混合声音、上传、生成、比较、稳定播放、草稿恢复、下载、乐谱导入、各层级删除确认/恢复/永久删除、历史音色名称、情绪强度草稿与修改历史版本及日夜响应布局。
- `npm run verify:score`：旧链接归属、按需乐谱工具、同片段比较、选段听评、下载、关闭停止播放、混音新版本、重新打开与响应布局。
- `npm run verify:tts:real`：显式开启的真实 IndexTTS 权重验收，需要本地模型。

自动检查证明操作与数据规则，不代表已取得目标用户可用性反馈。
