# 本机 TTS 模型选型

本页汇总已取得的本机证据，回答模型是否值得接入。每次试验的输入、版本、测量方法和失败记录放在带日期的验收记录中。当前正式用法见[语音创作](tts.md)。

## 当前判断

**采用 Breeze TTS 2 4bit，并保留 IndexTTS 兼容路径：有参考文字稿时使用 Breeze，留空使用 IndexTTS。** 用户接受本组克隆的可用性；高相似度目标仍未满足。接入验证见[兼容接入记录](testing/verification-breeze-integration-2026-10-26.md)。 三个 BF16 中文旁白样本已获得用户正面听评；4bit 三个设计音色样本均低于 5 GB，长旁白获用户“这段效果已经够用了”评价。官方样音克隆的两段也均低于 5 GB、自动转写与输入文字一致（忽略标点）；用户确认两段都可用，但都不太像姜文。该评价限定于本组 2.44 秒参考与运行配置。

| 候选与运行方式 | 本机效果证据 | 内存证据 | 选型状态 |
| --- | --- | --- | --- |
| IndexTTS 2.0 F16 / audio.cpp / Metal | 指定短句收尾修复已获用户试听确认；已接入正式音色、情绪与任务流程 | 历史指定样本约 4–5 GiB；2026-10-10 短句约 4.32 GiB | 无参考文字稿时的兼容方案 |
| VoxCPM2 4bit / MLX | 不用文字稿即可克隆；用户对“女网红”短句评价“还行，不是特别像，但是重音是对的” | 两段短句进程峰值约 4.58 / 4.61 GB；整段长稿触发 5 GB 保护；五段拼接实测最高单进程约 4.75 GB | 值得收录为候选；长稿衔接待听评，暂不替换正式方案 |
| Breeze TTS 2 BF16 / MLX / 整段波形还原 | 2026-10-26 三段自然中文旁白均获用户正面评价，38.4 秒长段被认为自然 | 本次三个进程峰值 13.30 / 12.93 / 23.94 GiB | 音质值得关注，当前资源成本不适合直接替换 |
| Breeze TTS 2 4bit / MLX / 流式波形还原 / 禁用空闲缓存 | 三段真实生成及文件检查通过；长旁白获用户“已经够用”评价，另两段短句及逐字完整性待确认 | 含加载峰值约 4.35–4.36 GB（4.05–4.06 GiB）；三个指定输入均低于 5 GB | 本组资源达标、长旁白听感可用 |
| Breeze TTS 2 4bit / 同一低内存配置 / 官方样音克隆 | 用户认为两段都可用，但都不太像姜文；短句音量偏小，长段音量正常，表达程度有差异 | 含加载、参考编码及生成峰值 4.356 / 4.375 GB（4.057 / 4.074 GiB） | 本组资源达标、语音可用；高相似度克隆尚不足，不外推到所有参考 |

**用户主观比较：Breeze 的重音、断句比 IndexTTS 强不少。** 用户认为 VoxCPM2 的长旁白与 IndexTTS 有相似的表演感，Breeze 则像深夜电台，情感丰富但不太像姜文；这属于所听样本和既有体验，不能当成所有音色的结论。 因此，面向自然旁白、故事表达的选型应重点考虑 Breeze；复刻特定人物声音的需求仍需另测相似度。这是用户基于本次试听和既有 IndexTTS 使用经验的评价，没有进行同正文、同参考、响度对齐的盲听对照，不作为客观全面排名。

## VoxCPM2 为什么值得观察

- **无需参考文字稿：**VoxCPM2 有仅凭参考录音克隆的模式，也能使用参考录音加文字稿做续读。前者可能让现有音色在缺少文字稿时也能使用新模型，效果有待试听，不能假定两种模式的音色或韵律相同。[官方能力说明](https://openbmb.cn/docs/en/guides/voxcpm/voxcpm-2)
- **中文与多语言：**官方列出 30 种语言及 9 种中文方言，支持按文字描述设计声音、控制情绪和语速；这不是本机语言覆盖或可控效果的验收结果。[官方模型卡](https://huggingface.co/openbmb/VoxCPM2)
- **许可：**截至 2026-10-27，官方 VoxCPM2 模型和代码标注 Apache-2.0，社区 MLX 4bit 模型卡同样标注 Apache-2.0；Breeze 自部署权重和输出有非商业限制。[VoxCPM2 模型卡](https://huggingface.co/openbmb/VoxCPM2)、[MLX 4bit 模型卡](https://huggingface.co/mlx-community/VoxCPM2-4bit)、[Breeze 模型许可](https://huggingface.co/BreezeBlue/Breeze-TTS-2/blob/main/LICENSE)。
- **能力边界：**VoxCPM2 是文字转语音与参考声音克隆模型；项目现有的音频 / 歌曲换音色仍属于 [Seed-VC](voice-conversion.md) 路径，不能根据 VoxCPM2 的参考声音功能推断它能等价替代。

本机同正文、同 2.44 秒参考的短句：VoxCPM2 无文字稿克隆耗时 24.97 秒、峰值 4.61 GB；Breeze 带文字稿克隆耗时 8.84 秒、峰值 4.36 GB。生成音频分别为 7.68 / 8.64 秒；模型、生成方式和设置不同，只能说明这组输入的实测差异。[2026-10-27 对照记录](testing/verification-voxcpm-2026-10-27.md)保存过程、失败记录与样音。

长稿需更细分段才能在本次输入上完成；用户已听评整体表演感，拼接是否造成音色漂移和断句问题仍需专门对照。其他音色、方言、情绪控制及长时间运行不能由这次结果推断。不能根据官方显卡性能或参数量判定本机速度、效果或资源占用。

Breeze 参考声音对照显示：本次只更换参考录音时，生成的时长、响度和波形均有变化；用户认为两版音色“有变化但不明显”，各版与参考人物的相似度未单独评价，见[2026-10-27 参考声音对照](testing/verification-breeze-reference-2026-10-27.md)。

这些记录来自同一台 M4 / 32 GiB，但**不是同台词、同音色、同测量方法的公平速度或音质排名**。IndexTTS 的历史峰值包含采样误差，Breeze 本次使用内核记录的进程生命周期峰值；均不能外推为任意输入的内存上限。

## 同正文、同参考的三款克隆

使用同一段正文与合成女声参考，并将试听音量粗略对齐后，用户对 Breeze、VoxCPM2 和 IndexTTS 的整体评价是：**各有利弊，没办法直接排名**。没有逐项评分，这不是盲听结果，也不能推断哪款更像参考或更自然。IndexTTS 在首次内存监测失败后，保留失败记录并完成同条件生成；这次未复现错误，原因尚不确定。[同参考对照记录](testing/verification-tts-clone-comparison-2026-10-27.md)保存音频条件、耗时和内存口径。

## 替换范围与兼容规则

| 项目功能 | 引擎与规则 |
| --- | --- |
| 输入文字生成语音 | 提供参考录音完整文字稿 `referenceText`，使用 Breeze 4bit；省略或空白使用 IndexTTS |
| 用参考声音生成新台词 | 两条 TTS 路径都保留；Breeze 需要准确文字稿，本组克隆相似度不高 |
| 给已有音频或歌曲换音色 | 保留 Seed-VC + HTDemucs；这项能力原本就不由 IndexTTS 提供，Breeze 不能取代这条链路 |
| 情绪描述、五档强度 | Breeze 接收完整自然语言指令；IndexTTS 保留原参数。档位不代表两种模型间相同强度 |
| 历史版本、音色库、取消与重试 | 保留数据和旧音频；版本保存实际引擎及参考文字稿，不回填或改写旧作品 |

文字稿是**参考录音说出的内容**，不是希望新生成的正文。用户选择自行提供，系统不强制转写。换参考时清空原稿，防止内容错配；生成失败报错，不偷偷切换模型。语音转写后重新朗读不能替代音频换声，因为不能保证原节奏、停顿与旋律。Breeze 官方能力及参数见[官方说明](https://github.com/breezeblue-ai/breeze-tts)。

## 验证边界

1. **内存：**本次组合已在三个设计音色输入和一个 2.44 秒参考的两个克隆输入达标，接入另测分段正文与 14.63 秒合成参考，仍需更广自然参考和长稳测试；不能承诺所有输入都不超过 5 GB。模型文件大小不能作为运行峰值，MLX 内存设置也不是整个进程的硬上限。
2. **听感：**低内存长旁白已获用户确认，其他样本继续检查咬字、停顿、音色、段落衔接和收尾。指定旁白反馈不代表声音克隆、复杂情绪或中英混读通过。
3. **产品能力：**克隆相似度及音色保持、更多参考音频、情绪描述、取消、重试和连续任务仍需验收。正式接入使用统一资源队列并在结束后释放；取消、兼容与分段结果另见接入记录。
4. **许可：**截至 2026-10-26，Breeze 源代码 Apache 2.0 不涵盖权重及自部署输出的商业使用；模型采用研究与非商业许可。商业产品接入需单独解决授权。见[模型许可](https://huggingface.co/BreezeBlue/Breeze-TTS-2/blob/main/LICENSE)。
