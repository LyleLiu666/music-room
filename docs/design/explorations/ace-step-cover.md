# 把这首歌翻唱一版

2026-11-24 · 产品提案。用户试听《把周末铺在湖边》V2 的沙哑女声摇滚版后，明确希望保留这项能力。本轮交付独立本机工具，工作台接入时机待定。

## 用户想做什么

用户喜欢一首歌的词和旋律，想听另一个人用不同的方式唱，乐队也可以跟着变。例如，把电子舞曲里的「周六的阳光爬上窗沿」交给沙哑女声和电吉他乐队演绎。验收时先听旋律是否还能认出来、词是否唱对，再听新的演绎值不值得留下。

## 今天怎么用

本机打开 `~/Music/ACE-Cover-Trial-20261124/开始翻唱.command`，选择原曲，填写起始秒数和这段歌词。风格直接回车会沿用试验中的沙哑女声摇滚配置，也可输入自己的英文风格描述。默认取 30 秒，单声道和立体声的 WAV、MP3、FLAC 均可作为输入；末尾不足 10 秒会提示重新选段。完成后打开本次作品目录，其中有原唱片段、翻唱、来源位置、生成配置和日志。

本机工具可供 Agent 直接调用。例如，在工具目录执行以下命令可用同一段歌词和节奏再生成一版。每次运行单独存入「翻唱作品」。

```sh
./开始翻唱.command original.wav --lyrics 湖边片段歌词.txt --bpm 128
```

首次试听原件保存在同目录的 before.wav 和 after.wav，两者已匹配响度。原选段为 V2 的 15–45 秒，中文八句，种子 71、8 步、原曲参考强度 0.625。首轮推理在标准 M4 上耗时 28.85 秒，模型进程峰值 1.64 GB。该数据仅覆盖这次 30 秒翻唱。[工具源码](../../../scripts/experiments/ace-cover.py)

## 将来放进 Music Room 的方式（提案）

从已有歌曲版本选「翻唱一版」，截取想听的主歌或副歌，核对该段歌词，选择或描述新的唱法与伴奏。完成后用同一片段来回试听原唱与翻唱，喜欢就保留为关联版本。现有「音色转换」继续服务于想保留唱法、节奏和原伴奏的用户。

待体验验证：用户选段时能否方便地拿到正确歌词；换一种风格后旋律和中文咬字能保留多少；听完短样后是否还需要整曲翻唱。当前反馈和内存数据均来自短片段。
