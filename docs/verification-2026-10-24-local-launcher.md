# 本机链接启动器验证

- 安装前 open music-room-local://start 报无应用处理（-10814）。
- 编译 Swift AppKit 启动器并安装到 ~/Applications/Music Room Launcher.app，注册固定协议。
- 安装后系统 open 调用成功；本机页面 HTTP 200，服务仍只监听 127.0.0.1:5174。
- 当前已有服务，验证了复用路径；本轮没有停止正在运行的服务来测试冷启动。实际启动复用既有已验证脚本。
- 导航上线，浏览器确认链接指向固定协议。内置浏览器安全策略阻止代点击外部应用，未绕过；首次网页到本机应用的交互仍需用户确认。
- 启动器不接受 URL 的命令、参数或路径，只处理完全匹配的 music-room-local://start。
