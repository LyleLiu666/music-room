# 音乐工作台开发记录

对应方案：[音乐工作台设计](music-workbench.md)。每轮完成开发、验证、代码复查与修复后单独提交。此文件记录已完成范围，不代替设计文档。

## 基线

现有项目此前没有 Git 仓库，已建立代码、音色、原始作品和设计文档基线。原有 10 项单元测试通过。

## 第一轮：目录与工作台

- 歌曲和版本以独立 ID 关联，目录校验分组、默认版本、独立文件路径与段落对应索引。
- 左侧作品库、整曲概览、4/8 小节局部查看和可展开混音器已实现；曲尾窗口显示实际剩余小节。
- 版本直达、无效地址提示、前进后退、普通切换停止旧声音有效；总音量保留，其他混音重置。
- 14 项单元测试通过；浏览器验证分组、局部窗口、段落跳转、实际播放、混音恢复、导航、MIDI 和 390 px 窄屏操作，无页面错误；构建通过。
- 代码复查修复：空格快捷键避开面板展开控件与其他交互控件，选中版本自动展开所属歌曲。试听和可视范围均不改写乐谱。
- 浏览器脚本：`npm run verify:workbench`；报告和截图位于忽略提交的 `test-results/workbench/`，不会覆盖原作品。

## 第二轮：片段选择与循环

- 选区吸附整小节，支持当前窗口、起止输入与框选；反向选择、曲尾、无选区和越界均有明确处理。
- 循环以音频时钟提前排程，下一轮从上一轮边界起算；暂停保留位置和循环，修改选区重新开始，选区外跳转退出循环。
- 持续音恢复与边界截断有效；每轮使用独立效果图，边界短淡入淡出，旧图按时清理。
- 代码复查修复：首次合成音色必须在确定音频启动时间前完成，否则第一轮可能缺失；片段结束使用音乐时间边界判断，避免浮点换算误纳入终点音符；手机框选禁用该区域滚动，普通浏览恢复滚动。
- 17 项单元测试、浏览器交互和构建通过。`npm run verify:loop-audio` 通过 AudioWorklet 记录实时输出，验证至少 20 轮节拍间隔（最近一次误差为 0）、逐轮波形一致、暂停输出归零，以及起点前持续音实际发声。
- 真实音频与界面报告位于 `test-results/`，不覆盖原作品。离线整曲导出保留独立状态与原先的尾声处理。

## 第三轮：A/B 版本比较

- 以明确共同段落 ID 和段内拍数映射位置与选区；速度不同、段落缺失/长度不同或跨段落选区会解释原因并禁用比较。
- 比较使用各版默认混音，共用总音量；轨道控件只读。切换保留播放/暂停、位置、选区和循环；比较切换不污染浏览器历史。
- 退出比较恢复进入前的版本、位置、混音、选区、循环及查看状态，保持暂停；普通选歌或浏览器导航结束比较并执行普通切换。
- 19 项单元测试与构建通过；`npm run verify:comparison` 验证实际播放中连续 20 次 A/B 切换、最后选择生效、退出快照恢复、跨段落拒绝、导航和 390 px 操作，无页面错误。
- 代码复查确认异步播放请求在版本切换后失效、导出引用仍指向实际当前版本；修复默认作品入口，使用歌曲目录的明确默认版本而非数组顺序。
- 复测发现选区更改后比较按钮存在一帧延迟；已让选择、跳转、循环操作同步更新比较资格，修复后重新验证再更新本轮提交。

## 第四轮：完整回归与交付

- 已在 `http://127.0.0.1:5174` 的静态构建产物上执行 `MUSIC_ROOM_URL=http://127.0.0.1:5174 npm run verify:all`，19 项单元测试、构建与全部五组浏览器验证通过，无页面错误。

- 音色按音高排序并固定等距采样选择，避免并行请求完成顺序改变声音。保留原音符与原件，验证脚本输出移到 `test-results/`。

- 最终代码复查覆盖状态同步、异步失效、播放边界、混音快照、目录身份与导航；修复后复测通过。仅调整样式格式时另用 CSS 语法树比较验证规则和值不变，最终构建 JS/CSS 文件名与完整验证时一致。

## 追加一轮：独立创作接口与短片段扩写

本轮边界：交付脱离项目源码的创作包、固定契约和独立校验器；页面本机 MIDI / JSON 选择与拖拽导入、作品/版本保存和备份恢复；以 4/8 小节起步，再基于当前版本扩写的提示词。完成 review、修复、验证后提交，不需要生产后台、账号或上线运维条件。

- 格式测试先失败，再实现共享校验器和存储事务；扩写与 MIDI 回归覆盖项目身份、短/长不同版本、对应片段 A/B 和旧作品交换。
- 创作包从唯一源目录生成，解压到全新临时目录后，无项目源码/包依赖执行校验。没有把 README 当作可运行接口替代品。
- 本机导入不覆盖旧版；保存失败、坏文件和冲突 ID 不改作品库或停止当前播放。下载的 JSON 包含版本和段落，MIDI 用于交换，WAV 使用原来的混音快照规则。
- Review 修复长标题撑宽手机页面、外部文本进入 HTML 模板、MIDI 侧击鼓 37 映射缺失；原两版的全部 MIDI 音符和创作 JSON 均可交换，原件继续由哈希与深比较保护。
- 完整回归又发现首遍循环效果器未完成准备，波形与后续循环不同。播放改为先初始化音色与效果器，再确定开始时间，并留 250 ms 静音准备；后续循环继续按音频时钟连续调度。实际录音用强制 100 ms 效果器初始化延迟复现并验证修复，首遍和二十轮后续比较阈值保持不变。操作测试改为等待音频位置推进，避开任意毫秒数假设。
- 26 项单元测试、构建、外部导入/工作台/实时循环/A/B/加载边界/完整音频六组真实 Chrome 检查均通过。导入播放用 AudioWorklet 实际 PCM 录音，20 秒 WAV 有声音；原 180 秒 WAV 为双声道 44100 Hz、峰值 0.6798303、削波 0，静音短文件准确。
- 拖拽验证包含进入高亮、完成复原、单个文件导入、多文件拒绝；创作步骤包含 4/8 小节提示词和带当前项目身份及附件名的扩写提示词。报告在 `test-results/imports/verification.json`，不覆盖原作品。

本轮完成的是创作和试听工具，不宣称 agent 创作的曲子自动达到审美验收。
