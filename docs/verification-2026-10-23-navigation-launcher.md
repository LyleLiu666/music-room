# 本机导航启动验收

- 修改前：根目录启动脚本可执行检查失败；线上导航预期四个入口，实际三个，浏览器断言失败。
- 新增根目录「启动 Music Room.command」，调用既有二进制；未修改服务与模型逻辑。
- 实际首次启动成功，地址为 http://127.0.0.1:5174；再次运行返回 reused=true，PID 未变。
- lsof 确认只监听 127.0.0.1:5174。没有部署到远端节点。
- 启动脚本通过系统 plutil 读取实际地址，再打开默认浏览器，不要求 Node/Python。
- 导航下载 ZIP 保留脚本可执行权限。浏览器下载后的 macOS 首次打开提示仍由用户处理；没有绕过系统限制。
- 本轮未测试生成音乐、模型加载或听感；这些能力未修改。
