# 翻唱与即兴故障恢复复验（2026-11-25）

## 修复与复现

| 场景 | 首次结果 | 修复后的断言 |
| --- | --- | --- |
| 彻底删除翻唱 | 版本索引的翻唱来源仍保留歌词和风格 | 副本和音频随版本清除。重新打开工作区时清理历史彻底删除记录。保留请求 ID 阻止旧请求重放，并校验原曲的音频。 |
| 演奏输出失败 | 演奏面板报失败，资源历史报取消 | 演奏和资源历史均记录失败。等待模型退出后，下一个会话可获得资源。 |
| 回留响应丢失、选段已过期 | 过期重试反复提交旧的播放位置 | 提交结果未知时沿用原请求，已提交片段只出现一次。确认播放位置过期后，可取当前播放位置重新保存。 |
| 停止请求未达、后台未确认释放 | 面板关闭时，演奏仍占用资源 | 面板保留重试入口。重试使用同一会话 ID，确认释放后收起面板。 |

测试在隔离工作区执行。服务首次失败见 `test-results/entropy-fixes-2026-11-25/service-first.log`，浏览器首次缺陷见同目录 `browser-first.log`。`unit.log` 保留了 Node 直接执行 TypeScript 时的语法失败。`chrome.log` 有四项在整机睡眠期间超过 90 秒取消，复验期间为测试进程持有防闲置睡眠断言，超时保持原值。

## 复验

- `npm test` 122 项通过，工作台构建通过。Chrome 受影响套件 16 项通过，WebKit 23 项通过。
- 服务全量 445 项通过。后续审查另复现了资源释放失败仍标为「已停止」，修正后运行翻唱、即兴和服务启动专项，10 项通过。首次失败见 `lease-first.log`，复验见 `lease-final.log`。
- 独立包首轮构建在测试启动工厂的类型检查失败，补齐显式工厂适配。首次日志见 `package.log`。
- 最终独立包通过 24 项检查和签名校验。SHA-256 为 `8d5a2c4150b345a420e7a1ec31b336df912c5db70571e7194d5eb18b6f4f1b4f`。
- 使用最终独立包在隔离工作区启动真实 Magenta。浏览器模拟首次停止请求未到达，此时模型进程及监管进程仍持有租约。点击「重试停止」后约 224 毫秒收起面板，后台确认同一会话已停止，进程租约和会话临时目录均已释放。记录见 `native-stop.log`。日常服务继续由原进程提供。
