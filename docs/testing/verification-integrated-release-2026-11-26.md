- 内存：预算充足时允许在轻度压力下启动；危险压力、应用预算、系统预留和运行中保护继续生效。8 GiB 是部分任务的需求，不是所有任务的固定占用保证。

- 历史失败：直接展示当时保存的原因，重试按当前状态重新检查，不用新策略解释旧故障。
