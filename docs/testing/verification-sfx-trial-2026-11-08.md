# 音效模型隔离试验（2026-11-08）

本页为接入前试验；正式实现与验收见[音效接入记录](verification-sound-effects-integration-2026-11-08.md)。

本次只验证四个 5 秒样本，未将音效生成接入正式工作台或独立包，人工听评待完成。

- 机器：Apple M4，32 GiB，macOS，Apple Silicon；模型 Stable Audio 3 Small-SFX，官方 MLX 运行代码 commit `790793b89ddceea612be9ce42ff6830d18f6fa57`，模型 revision `30cb2644da54bfa63275d1bc7f1fa67fc718680f`，MLX 0.32.3，seed 42。
- 通过项目资源协调器申请用户级重型任务租约，逐个执行，启动与运行保护均为 5,000,000,000 字节；另在模型进程中监测生命周期峰值，超过 5 GB 则退出。采样和进程自检不是瞬时硬上限。
- 四个 WAV 均为 44.1 kHz、双声道、5 秒；检查数据有限且非静音。通过已有声音库导入接口保存，再读取并逐字节核对四个文件。未评价是否逼真或满足剪辑用途。
- 模型进程生命周期峰值：碎纸机 1,636,304,792 字节；打字 1,532,151,752 字节；接水 1,519,880,088 字节；水桶咕噜 1,725,401,032 字节。只说明这四次输入，不代表任意时长和设置都低于 5 GB。
- 模型默认 Xet 下载约 50 秒无进展，手动中止并改用普通下载；随后 DiT 下载连接中断一次（已接收 434,011,478 / 919,193,814 字节），下载工具续传完成。原始下载说明、输入、生成日志、资源状态、音频校验和样本位于本机 `test-results/sfx-trial-2026-11-08/`，不提交。
- 样本在声音库中以“音效试验 ·”开头；导入身份是外部导入。模型、试验脚本和环境目前位于临时目录及本机下载缓存，不能当作正式安装或用户可重复生成的功能。

## 3 秒补充试验

同一环境顺序生成水桶咕噜三个版本（seed 101、202、303）、饮水机接水（404）和碎纸机（505）；提示词、日志、资源状态和 WAV 位于 `test-results/sfx-trial-3s-2026-11-08/`。五段均为 3 秒、44.1 kHz 双声道，检查有限且非静音；模型进程最高生命周期峰值为 1,729,087,312 字节。五段均导入声音库，并从服务读取后逐字节与原件核对。声音是否符合预期待用户试听；以上结果不构成正式模型接入验收。
