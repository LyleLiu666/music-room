# 声音创作空间

## 主流程

首页按 **项目 → 声音 → 版本** 组织。项目可同时包含音乐片段、完整音乐和语音。用户选择声音类型，不按模型选择入口。

1. 创建项目，只填写名称。
2. 新建声音，选择类型和名称。
3. 填写创作要求；音乐使用 YuE2，普通语音使用 IndexTTS 2.0。
4. 试听结果，再创作、保留灵感、选为成品或删除。

默认工作区只展示当前声音的播放器和版本列表。「再创作一版」打开创作表单；「修改这版」带入原始要求并记录来源。表单草稿随声音保存，不随试听版本切换丢失。

## 语音情绪

情绪描述指定「是什么情绪」，情绪强度指定「表现得多明显」。表单提供「情绪平淡 / 情绪一般 / 情绪强烈」，新创作默认一般；描述留空时强度也用于调节参考人声的情绪影响。强度不承诺某一种音调或中性效果。

草稿和版本独立保存设置，「修改这版」带回原值。历史记录缺少强度时保留原参数规则，不因新默认改变重放行为；表单显示原规则对应档位，用户主动换档后才写入新设置。三个数值目前为试听候选，见[推理引擎说明](../tts-native-engine.md)。

## 次要操作

- 项目、片段和音色名称旁的「⋯」：重命名、删除。项目和片段删除前展示包含的片段与版本数量。
- 版本菜单：查看创作要求、删除；版本列表展示生成时的音色和情绪，音色改名或删除后保留历史名称。极旧记录缺少名称快照时，首次读取保存现存名称，音色已不存在则显示「历史音色」，不推测原名。乐谱版本另有 MIDI 下载与音轨编辑。
- 导入与 Agent 创作：将 MIDI / JSON 导入当前声音，或复制携带项目、声音、来源的要求。复制不表示已经启动 Agent。
- 设置：模型安装、启动、日志、目录和 MCP 连接信息。
- 项目成品：下载各声音已选的版本。
- 侧栏回收站：统一查看项目、片段、版本和音色，支持恢复与需再次确认的彻底删除。父级在回收站时，子项随父级显示，恢复父级后再分别管理。

没有音频的乐谱必须先生成试听文件。只有音频的版本不显示虚假的 MIDI、分轨或转录能力。音乐描述可提出期望长度，但页面不承诺模型精确控制时长。

## 删除与恢复规则

项目和片段使用独立删除标记，其下内容随所属层级隐藏。恢复时保留原来的片段、版本状态及成品选择；之前单独删除的版本继续留在回收站。单个版本删除会清除该版本的成品选择，单独恢复版本不重新选成品。

音色移入回收站后退出可选列表；生成时的音色名称保存在版本中，已有音频继续可用。参考人声正在清理或被排队/运行任务使用时，拒绝删除音色。项目、片段和版本包含未完成的生成或乐谱渲染时，需要先取消或等待完成。

彻底删除只允许处理回收站中的内容，移除该范围内保存的音频、乐谱、原音及处理后人声。全局音色独立于项目；彻底删除项目保留共享音色。保留必要的来源 ID 标记，防止旧乐谱、引擎任务及内置音色在重启或自动导入时重新出现。中途失败时保存已完成删除的记录，可继续重试；已完成的永久删除不能通过恢复撤销。

## 持久化与兼容

`studio.json` 保存声音归属、音乐版本输入、来源、灵感、成品和回收站状态。语音原始记录由 `speech/library.json` 保存；工作区同步它的真实状态。音频和乐谱仍使用原引擎的持久文件。

旧乐谱项目首次读取时作为一个声音纳入原项目。旧语音保持项目、声音和版本 ID；旧 YuE2 任务没有项目归属，单独收纳到「以前生成的音乐」。迁移不覆盖、移动或删除原文件。

新生成任务在提交时绑定声音；后续切换项目或声音不会改变结果归属。新版本不替换已选成品。删除有后代的版本不删除后代。

入口：`/` 为正式创作空间；`/speech.html` 为同页兼容入口；`/score.html#版本ID` 为 MIDI 编辑器。

## 验证

- `npm run test:service`：后端所有权、迁移、跨项目乐谱导入、层级删除恢复、忙碌保护、永久删除重试、种子内容与内置音色防重建、重启及原有生成/文件边界。
- `npm run verify:studio`：使用隔离工作目录和测试引擎走正式首页，覆盖混合声音、上传、生成、比较、稳定播放、草稿恢复、下载、乐谱导入、各层级删除确认/恢复/永久删除、历史音色名称、情绪强度草稿与修改历史版本及日夜响应布局。
- `npm run verify:tts:real`：显式开启的真实 IndexTTS 权重验收，需要本地模型。

自动检查证明操作与数据规则，不代表已取得目标用户可用性反馈。
