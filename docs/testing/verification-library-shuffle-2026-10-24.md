# 2026-10-24 随机播放验收

## 结论与行为

声音库及播放列表已支持随机播放，本机预览服务已更新到 `http://127.0.0.1:5174`，刷新页面后生效。

- “播放全部”右侧菜单提供顺序播放和随机播放，不增加常驻工具栏行。操作覆盖当前筛选结果或播放列表的全部页。
- 随机播放生成一份完整临时队列，一轮内不重复、不遗漏，末尾停止。上一首、下一首沿此顺序移动。
- 底栏播放方式增加“随机”；切换时保留当前声音及已加载音频，切回其他方式恢复原队列顺序。再次选择已经启用的随机方式不重新洗牌。
- 刷新保留随机顺序、当前位置与进度，保持暂停。删除、追加和指定下一首同步维护队列；保存的播放列表不因随机播放而改变。
- 空、单首、重复 ID 与 20,000 首队列均有边界覆盖；只打乱 ID，仍按需读取当前音频。

播放顺序规则与排列测试放在 `src/workbench/studio/listening-order.ts` 及相邻测试；持续音频、异步读取及界面仍由 `ListeningQueue` 管理。未修改服务端、模型、音频处理或资源策略。

基于 `b56fc33` 和此前未提交的界面、分页及播放列表修改。环境：macOS 27.0.1 / arm64、Node 25.3.0、Bun 1.4.2、Chrome 156.0.8078.47、Playwright WebKit 27.2。
