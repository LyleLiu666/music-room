## 改动与乐句

- 钢琴主题从第一拍进入，用短音、切分推动，不再以长音和等待为主。
- 主 riff：F♯4–A4–E5–D5｜C♯5–B4–A4–F♯4。前一小节第二音在第一拍后 0.75 拍进入，第三音在第二拍后半进入。
- 回答句：B4–D5–C♯5–B4｜A4–G4–F♯4。第 5—6 小节保留 riff 节奏，最高音从 E5 抬至 F♯5。
- 和弦以短促的三次击奏为主；贝斯前七小节每小节四次击奏，踩镲保持八分脉冲，底鼓与贝斯呼应，军鼓反拍更清晰。
- 第 7—8 小节收束，最后 D5 延长 2.75 拍，留半拍音符空白。保留长音作为结尾，不让整句变成连续跑音。

配器仍为钢琴旋律、钢琴和弦、贝斯、轻鼓。和声与 v1 相同。节奏更密、更短促是可验证的变化；是否足够有推进感，仍须试听判断。
