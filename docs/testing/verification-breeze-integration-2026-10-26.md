# Breeze / IndexTTS 兼容接入（2026-10-26）

## 行为

Apple Silicon 默认按显式参数选择 TTS：`referenceText` 非空使用 Breeze TTS 2 / MLX 4bit，省略或空白使用 IndexTTS 2.0 / audio.cpp F16。文字稿对应参考录音，最多 2000 字，不是生成正文。不强制自动转写，失败不自动切换模型。其他平台及显式 `MUSIC_ROOM_TTS_BACKEND=python/audio-cpp` 保留旧后端。

页面增加参考文字稿输入，切换参考时清空；草稿、版本、再创作保留文字稿，版本详情显示实际模型。既有音色、音频、版本不重写。音频换音色仍使用 Seed-VC / HTDemucs，与本次 TTS 选择无关。

Breeze 每段最多 140 字，串行、流式波形还原；结束退出进程。五档情绪组成自然语言指令，不复用 IndexTTS alpha。未给情绪描述和档位的 API 请求为纯克隆。任务进入正式资源队列，预约 5,000,000,000 字节，另每 200 ms 检查内核记录的 Python 进程生命周期峰值。采样停止不是瞬时硬上限，也不是所有输入完成的承诺。

## 真实模型

环境：Apple M4 / 32 GiB；模型、MLX 与依赖来自[试听记录](verification-breeze-2026-10-26.md)的固定版本。安装到 `~/Music/IndexTTS2/breeze/`，独立 Python 3.12.12 环境；模型复用已核验下载，逐文件 SHA-256 验证。参考为 2.4387 秒官方样音；文字稿“翻译翻译，什么叫惊喜？”来自先前机器转写。
