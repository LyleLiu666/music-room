# 安静信笺 · 视觉稿

[prototype.html](prototype.html) 是[创作空间整体改造方案](../../studio-redesign.md)的视觉参考，**不是正式页面**。时长、进度、内存数值为示意。

打开方式：浏览器直接打开文件，左下角切换条可切换「工作区 / 更多菜单 / 创作面板 / 新声音 / 声音库 / 任务与资源 / 设置 / 夜间」；窗口窄于 720px 时显示手机布局。地址加 `?shot` 隐藏切换条，加 `?theme=dark` 进入夜间。

| 文件 | 内容 |
| --- | --- |
| `before-*.png` | 2026-11-19 改造前的正式页面（隔离工作目录、测试驱动数据） |
| `after-*.png` | 视觉稿对应画面：workspace、menu、compose、compose-1280（侧栏收起）、newsound、library、tasks、tasks-dark、settings、mobile、dark |

规则以方案文档为准；视觉稿与文档不一致时按文档执行，并同步更新视觉稿。
