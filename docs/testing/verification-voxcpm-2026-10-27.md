# VoxCPM2 与 Breeze 本机对照（2026-10-27）

## 结论

VoxCPM2 值得作为 TTS 候选收录，主要价值是支持无需文字稿的参考音色克隆，以及模型和代码的 Apache-2.0 许可。是否接入取决于本机资源、语音质量、已有功能兼容性与用户试听，当前未替换正式引擎。

官方 VoxCPM2 是 2B 多语言文字转语音模型，支持中文、声音设计、参考声音克隆、情绪和语速描述。参考录音单独输入可克隆；参考录音和准确文字稿可用于续读，两种模式分别评估。官方声明的 30 种语言、9 种中文方言与 48 kHz 输出见[模型说明](https://openbmb.cn/docs/en/guides/voxcpm/voxcpm-2)。模型、代码及所测社区量化模型标注 Apache-2.0，见[官方模型卡](https://huggingface.co/openbmb/VoxCPM2)和 [MLX 4bit 模型卡](https://huggingface.co/mlx-community/VoxCPM2-4bit)。Breeze 自部署模型权重及输出的[许可](https://huggingface.co/BreezeBlue/Breeze-TTS-2/blob/main/LICENSE)限定研究与非商业用途。具体项目使用仍应核对所有相关组件和音色授权。

VoxCPM2 是 TTS，不能据此视为已有音频 / 歌曲换音色功能；当前项目的 Seed-VC 转换链继续独立使用。

## 本机实验方案

Apple M4、32 GiB，macOS 27.0.1；使用 `mlx-community/VoxCPM2-4bit`、`mlx-audio` 0.6.1（Git `3674813a24db8cb9e6ff816a8dfe1834741b179d`）、MLX 0.32.4、Python 3.12。固定模型版本 `dc9e5c187858da5f4a13dc4c247e297339216381`，通过 ModelScope 获取的文件与 Hugging Face 固定版本逐项校验。

与 Breeze 使用同一份 2.44 秒官方样音、相同短句和长旁白；无文字稿克隆为主要比较，另试 14.98 秒“女网红”参考、同参考带机器文字稿的续读，以及同一女性声音描述的长旁白设计。采用 4bit、种子 42、10 步、CFG 2、空闲缓存上限 0，串行运行，每项新进程；模型推理 API 本轮整段解码。进程生命周期物理峰值每 200 ms 检查，超过 **5,000,000,000 字节**停止；同时采用用户级资源租约、正式资源探测与队列保护。MLX 内存设置和采样停止不是瞬时硬上限。实验目录：`~/Music/VoxCPM2-Trial/2026-10-27/`。

相同输入也不表示采样参数、采样率、生成时间或模型模式完全相同；结果用于实际试听和资源判断，不是严格的双盲模型排名。自动转写可以检查内容，但不能代替对音色、停顿、重音和表达的人工听评。

## 实测结果

“女网红”参考录音 14.98 秒，未传入文字稿。2026-10-27 用户对生成的短旁白评价：**“还行，不是特别像，但是重音是对的。”** 这是这一条音频的主观评价，不推广到其他音色和正文。

短句测试：女网红参考的 VoxCPM2 进程生命周期峰值 4,580,674,344 字节，2.44 秒官方参考短句为 4,611,640,416 字节，均包含模型加载及生成。两者分别生成 6.56 / 7.68 秒音频，推理耗时 24.13 / 24.97 秒（不含加载）。这是指定样本，不是任意输入的内存保证。

同一 2.44 秒官方参考与完整长旁白整段生成时，正式资源监测记录的任务占用达到 5,041,903,400 字节，触发 5 GB 保护并停止，未生成完整音频。这次是失败结果，不因后续优化覆盖或删除。采样式保护可能在越界后才停止，不能视为瞬时硬限制。

同一长稿的文字设计声音整段生成也触发了进程 5 GB 保护，未完成。另行按句子拆为三段、每段重新加载：第一段完成、其余两段仍超过 5 GB。再次把未完成的两段按句末拆为四个更短输入，四个都完成；与第一段拼成五段、31.36 秒的音频。这是新的分段配置，不覆盖先前失败，也不改变 5 GB 限额。五次生成耗时总计 97.28 秒，加载总计 5.52 秒；最高单进程峰值 4,745,055,400 字节。拼接没有额外做响度或过渡处理；用户认为整体有表演感，分段是否导致音色漂移和断句问题尚未单独确认。

以上进程生命周期峰值与任务采样峰值不是同一口径。两模型使用不同的生成方式、输出长度和采样设置；本组结果反映实际体验，不是同参数的标准性能排名。VoxCPM2 五段比 Breeze 整段耗时更长，也可能产生片段之间的音色或停顿变化，不能据此认定所有情形都同样慢或不自然。

独立 Qwen3-ASR-0.6B 在 TTS 进程退出后，分别转写三条完整短句和五段拼接长稿；四份转写均与输入文字一致（忽略标点）。各生成文件为单声道 48 kHz WAV，检查为可读、非静音且无削波；拼接文件与片段的 SHA-256 均核对。ASR 是内容检查，不能代替用户听评，也不证明音色相似。

下载先以单连接获取，随后主动切换为按字节范围续传；保留原始下载日志和续传区间，完整文件通过上游固定版本的 SHA-256 校验。模型下载、逐项结果、原文、峰值、文件哈希、独立转写与用户反馈见[机器可读证据](../evidence/voxcpm2-2026-10-27.json)；实际样音和完整日志留在本机实验目录。

2026-10-27 用户补充听评：VoxCPM2 与既有 IndexTTS 听感都带有明显的表演性质；Breeze 像深夜电台，情感丰富，但不太像姜文。用户怀疑 Breeze 的参考音色未生效，此为待验证假设，不等于模型未读取参考。
