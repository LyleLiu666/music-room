# 内存预算充足时的启动规则（2026-11-26）

## 行为

- 系统压力偏高（warning）作为提醒，启动预算满足任务预约就允许执行。应用上限、系统保留量和 1 GiB 启动余量不变。
- 系统压力危险（critical）、启动预算不足或指标不可靠时仍不能启动。8 GiB 启动预约需要至少 9 GiB 系统可用估计，同时应用剩余额度需达到 8 GiB。
- 运行中的任务上限、危险压力、警告压力伴随交换增长和监测失败保护保持不变；已有且稳定的交换占用不单独阻止任务。
- 任务页、各功能状态、侧栏及等待失败提示与后台规则一致。同步歌词也使用此规则，其启动预约仍为 4 GiB、运行上限最高 8 GiB。

本次解决预算足够时的过度等待，不改变音频时长检查，也不修改任务内存上限。此策略调整基于允许预算充足任务启动的产品要求，不是为了让性能或资源超限测试通过而抬高阈值。
