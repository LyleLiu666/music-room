# YuE2 独立试用

两个页面共用独立乐谱版本与任务记录，不写入正式项目、版本库或 YuE2 Studio 任务数据库。

## 启动与使用

在仓库根目录运行 `npm run trials:yue2`。需要 Node.js、`python3`、已安装的本机 YuE2 环境；首次运行仓库时先执行 `npm install` 和 `npm run build`，生成内存监测程序。

- http://127.0.0.1:4321/transfer ：将 Vocal 主旋律转到 Ins；默认遇到重叠即停止，可明确选择主旋律优先。
- http://127.0.0.1:4321/edit ：导出 AI / LLM 改谱需求包、验证并保存完整 ABC 提案、重复或删除明确段落。

“01 写谱与按谱生成”页面已移除，旧 `/plan` 地址跳转到 `/transfer`。先在任一页面右侧导入已有音乐对应的 ABC，再选择版本操作；查看、试听、下载和按谱生成继续保留。所有修改另存版本。生成前可改变声音描述、种子和质量；音乐类型与歌词沿用该乐谱版本，不能悄悄改变。

改谱页面没有内置聊天模型。将下载的需求包交给当前 AI / LLM，把修改后的完整 ABC 粘贴回页面检查。也可以由 AI / LLM 使用需求包中 `/api/proposal` 接口：先 GET `/api/state` 获取本地会话 token，再用同源 `Origin`、`X-Trial-Token` 与 `application/json` 提交。仅改和弦/速度时不允许修改歌词。段落操作使用明确下拉选择，自动同步对应歌词。

默认数据目录：`~/Music/MusicRoom/experiments/yue2`。默认模型目录：`~/Music/YuE2`。可分别用 `MUSIC_TRIAL_DIRECTORY`、`MUSIC_TRIAL_ENGINE`、`MUSIC_TRIAL_PORT` 覆盖。不要把试用数据目录设置为正式业务目录。停止服务按 Ctrl+C；重启将未结束任务标为中断，不会自动恢复。

## 能力边界

- 支持固定版本 YuE2 原生双声部 ABC，不是通用 ABC 编辑器；不支持的记谱会明确报错。
- 简易试听最多播放前 120 秒，不代表 YuE2 音色。
- 纯音乐通过明确参数、纯音乐 LoRA、段落标签和器乐提示约束。不会加入人声识别或人工审核下载门槛。
- 生成结果是否符合风格、是否出现模型自身的人声偏差，通过试听评价；项目保证输入与所选版本对应。
- 和弦编辑保留两个声部的精确音高/起音/时值、拍号、调号、速度和段落。速度编辑还保留和弦。段落操作拒绝边界延音、中途变拍变调或歌词无法一一对应的情况。
- 只写谱任务不会调用音频阶段。写谱截断或格式无效会保留原始任务文件并提示失败，不会自动补谱。
- 音频重新生成整段；不保证未编辑位置的波形相同。
- 没有正式项目导入/回写接口，没有 cover、哼唱转谱、声音克隆入口。

## 数据与执行

`index.json` 保存试用索引；`scores/<id>/score.abc` 与 `version.json` 保存不可变版本；`jobs/<id>/request.json` 保存实际请求，模型结果保存在同一任务目录的 `plan/`、`song/`。导出按钮下载完整版本/请求/反馈 JSON；音频单独下载。

模型每次在独立子进程中执行，只读取已安装的模型目录，缓存及运行配置进入任务目录。任务复用现有全用户资源租约、内存预算与进程监督，结束/取消后卸载。页面浏览和乐谱变换不加载模型。

`model.py` 是针对锁定 Studio 版本 `f696147a985081848d4b0310cbe9b10b16259be6` 的薄适配层，使用已有低内存管线与保守预算；升级模型环境时须重新验证阶段接口。`public/yue2-score/vendor/` 是正式工作台与试用页共用的固定提交的官方 ABC 工具源码，来源与许可证见其 README 和 LICENSE，不在运行时下载。

## 验证

`npm run test:trials` 运行乐谱协议、阶段边界、版本/参数与真实浏览器测试。浏览器测试使用独立临时目录和明确的假模型，不代表真实音质验证。`npm run build` 验证现有应用构建。

真实模型验证记录见 [验收记录](../../../docs/design/yue2-trials-validation.md)。
